# ADMARKET AI Media Buyer v1.9.0

## Что нового
- Полный визуальный апгрейд Dark Premium: графит, лаймовый акцент, новые поверхности, навигация и типографика.
- Главная страница с более ясной иерархией: AI-медиабайер, медиаплан, быстрый подбор и маркетплейс.
- Расширены фильтры каталога: канал, география, верхняя граница цены, минимальная аудитория; сортировка и сравнение до трёх площадок.
- Кабинет с быстрыми действиями, различающимися по роли рекламодателя и поставщика.
- Аналитика с KPI, отдельным блоком sandbox-финансов и реестром размещений.
- Обновлённый журнал операций и навигация по разделам админ-панели.
- Адаптация для широких мониторов, планшетов и смартфонов.

## Сохранность и ограничения
- База данных и миграции не изменялись.
- Существующие маршруты, формы, API и бизнес-процессы сохранены.
- Админ-доступ по-прежнему ограничен серверной проверкой роли и allowlist email `admin@example.com`.
- Платежи остаются исключительно тестовыми; реальные списания и выплаты не включены.

## Обновление
1. Останови сервер.
2. Сделай резервную копию каталога `data` целиком.
3. Обнови файлы приложения из архива, не удаляя `data/admarket.db` и `data/dispute_evidence`.
4. Установи зависимости при необходимости: `pip install -r requirements.txt`.
5. Запусти приложение и проверь `/health` — ожидаемая версия `1.9.0`.
