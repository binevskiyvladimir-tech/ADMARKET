# ADMARKET v1.7.0

## Ограничение доступа администратора

Админ-панель доступна только авторизованному аккаунту `admin@example.com`, у которого в базе данных установлена роль `admin`. Все маршруты, использующие `require_user(..., "admin")`, проверяют одновременно роль и точный email на сервере. Прямой переход по URL и ручной HTTP-запрос не обходят проверку. Аккаунты с ролью `admin`, но другим email, получают HTTP 403.

`ADMIN_EMAIL` в `.env` должен совпадать с разрешённым адресом. Для создания/первичной настройки администратора задайте `ADMIN_PASSWORD` (не менее 12 символов). Если разрешённый email уже занят обычным аккаунтом, bootstrap намеренно остановится с ошибкой — не меняйте роль автоматически, сначала проверьте существующую учётную запись.

Изменение не меняет схему БД и не затрагивает существующие данные. Перед обновлением сделайте резервную копию `data/admarket.db`.
