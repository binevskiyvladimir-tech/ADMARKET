# ADMARKET AI Media Buyer v1.8.0

## Desktop + mobile
- Полноценная широкоформатная компоновка для ПК и ноутбуков.
- Увеличенная рабочая область, улучшенные сетки каталога и кабинетов.
- Новая desktop-визуализация медиаплана на главной странице.
- Адаптивный планшетный и мобильный режим сохранён.
- Улучшены клавиатурная навигация и режим reduced motion.

## Совместимость и безопасность
- Бизнес-логика, API, SQLite-схема и миграции сохранены без изменений.
- Ограничение админ-панели и admin API только для `admin@example.com` сохранено.
- Платежи остаются в sandbox; реальные списания не выполняются.

## Обновление
Сделайте резервную копию `data/admarket.db`, обновите файлы приложения и сохраните каталог `data`.
